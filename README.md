## Requirements

- Python 3
- Standard library only (tkinter, unittest) for the program itself
- Development tools: flake8 and black (see `requirements-dev.txt`)

## Installation

1. Clone this repository.
2. (Optional) Create and activate a virtual environment:

   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. (Optional) Install the development tools:

   ```
   pip install -r requirements-dev.txt
   ```
